# data-science-portfolio

My data science portfolio, published with GitHub Pages.

**Live site:** <https://penglongrui.github.io/data-science-portfolio/>

## What is in here

| File | Purpose |
|---|---|
| `index.md` | The site entry page — GitHub Pages renders this Markdown file as the home page |
| `_config.yml` | Site title, description and the `jekyll-theme-cayman` theme |
| `assets/css/style.scss` | Custom styling layered on top of the theme |
| `images/` | Figures taken from the showcased project |

## The featured project

*"Do penguins get bigger because of the island they live on — or because of their species?"* —
a reproducible analysis of the Palmer Penguins dataset that separates a real biological signal
(species) from a structural artefact of the sampling design (island).

- **Code and full write-up:** <https://github.com/penglongrui/data-science-project>
- **Data:** Palmer Archipelago penguin data, CC0 1.0 public domain (Palmer Station LTER /
  `palmerpenguins` authors)
- **Status:** Completed

## Publishing notes

The site is served from the `main` branch, root folder, via **Settings → Pages →
Deploy from a branch**. A rebuild usually finishes within a minute of each push; progress can be
followed under the **Actions** tab.

No personal data, credentials or restricted datasets are published in this repository.
